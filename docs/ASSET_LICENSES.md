# Asset licenses

## Bundled fonts

All fonts are self-hosted through Fontsource and loaded on demand. Package versions and license metadata are checked into `package-lock.json`; each package also includes its copyright notice and full OFL text.

| Family | Package | Version | Script coverage used by the app | License and attribution |
|---|---|---:|---|---|
| IBM Plex Sans | `@fontsource/ibm-plex-sans` | 5.3.0 | Latin | OFL-1.1; Copyright 2019 IBM Corp. |
| IBM Plex Sans Arabic | `@fontsource/ibm-plex-sans-arabic` | 5.3.0 | Arabic and Latin | OFL-1.1; Copyright 2019 IBM Corp. |
| JetBrains Mono | `@fontsource/jetbrains-mono` | 5.3.0 | Latin | OFL-1.1; Copyright 2020 The JetBrains Mono Project Authors. |
| Noto Sans Coptic | `@fontsource/noto-sans-coptic` | 5.3.0 | Coptic (requested only for Coptic text) | OFL-1.1; Copyright 2022 The Noto Project Authors. |

Fontsource's [Noto Sans Coptic license page](https://fontsource.org/fonts/noto-sans-coptic/about) lists OFL-1.1 and attributes the font to the Noto Project Authors. Upstream source: [notofonts/coptic](https://github.com/notofonts/coptic).
